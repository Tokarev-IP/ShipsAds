# Pirate Playable Ad

2D playable ad prototype built in Unity (C#).

| Active Gameplay | Idle / Timeout Flow |

## Features
- Instant combat start with a pirate hook pointer and **Fire** button
- Two completion paths: player action or idle timeout
- Smooth transitions and end-card screen

## Engine
- Unity 2D (C#)
